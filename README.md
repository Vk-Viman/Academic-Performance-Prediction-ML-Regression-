# Academic Performance Prediction (ML)

Repository reorganized into a clearer structure.

Project layout

- `data/`
  - `students.csv` — raw dataset (messy, real-world)  

- `models/`
  - `student_model.py` — Logistic Regression (classification)
  - `student_regression_linear.py` — Linear Regression (regression)
  - `student_regression_rf.py` — Random Forest Regressor

- `analysis/`
  - `linear_feature_importance.py` — Linear Regression coefficient analysis
  - `rf_feature_importance.py` — Random Forest importance extraction
  - `rf_feature_plot.py` — Visual feature importance plot (saves to `images/`)

- `images/`
  - `feature_importance.png` — output image (generated by `analysis/rf_feature_plot.py`)

Quick usage

1. Create and activate a virtual environment (recommended):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

2. Run a model script, e.g.: `python models/student_regression_rf.py`.

Notes

- Scripts were adjusted to load the dataset from `data/students.csv`.
- The dataset is included in `data/` and kept as CSV for reproducibility.
